# Bivariate-Dose-Response-Model
Code to fit the bivariate (two-stressor) dose-response model used in Curé et al. (2025) to assess the influence of source distance and received level on sperm whale response onset thresholds.


Curé C, Isojunno S, Wensveen PJ, Siemensma ML, von Benda-Beckmann AM, Kvadsheim PH,  Burslem A, Benti B, Roland R, Lam FPA, Miller PJO (2025) Severity scoring of sperm whale (Physeter macrocephalus) behavioral responses to an operational sonar source reveals importance of received level and source-receiver distance. Aquatic Mammals 51(5):8–27. https://doi.org/10.1578/AM.51.5.2025.8
